# Бот-блокнот: база записей в Telegram

Личный бот, который запоминает записи (имя, телефон, заметка), показывает список и ищет по имени. Данные хранятся в простом файле SQLite. Это готовая основа к Дню 4 курса «ИИ-боты для турагентов».

## Что нужно заранее

1. Аккаунт в Telegram.
2. Токен бота. Открой Telegram, найди @BotFather, отправь команду `/newbot`, придумай имя и username. BotFather пришлёт токен (длинную строку из цифр и букв). Сохрани его в менеджер паролей. Токен нельзя писать в код, в чат и в «Избранное».
3. Аккаунты GitHub и Railway, как в Дне 0 курса.
4. Свой Telegram ID. Его показывает команда `/id` у бота из Дня 0 курса. Нужен, чтобы базой пользовалась только ты.

## Как запустить на Railway (круглосуточно)

Так боты работают на курсе: даже когда компьютер выключен, бот отвечает в Telegram.

1. На этой странице нажми кнопку **Fork** справа вверху. У тебя появится своя копия репозитория на твоём GitHub. Дальше работай только со своей копией.
2. Войди на [railway.app](https://railway.app) через GitHub (как в Дне 0 курса).
3. Нажми **New → GitHub Repository** и выбери свою копию этого репозитория. Если Railway не видит репозиторий, при подключении GitHub разреши доступ к нему (или ко всем своим репозиториям).
4. Сразу открой **Variables** и добавь переменные из таблицы ниже. Первый запуск без переменных может завершиться ошибкой, это нормально: после добавления Railway перезапустит бота.
5. Напиши боту в Telegram команду `/start` и проверь, что он отвечает.

Если не хочешь делать Fork, скачай файлы (зелёная кнопка **Code → Download ZIP**) и загрузи их в свой пустой репозиторий, как в уроке: **Add file → Upload files**. Потом в Railway подключи уже свой репозиторий.

## Переменные (Railway → Variables)

| Переменная | Обязательна? | Что это и где взять |
|---|---|---|
| `BOT_TOKEN` | да | токен из @BotFather |
| `OWNER_ID` | да | твой Telegram ID, только цифры, без пробелов и без `@`. Его показывает команда `/id` у бота из Дня 0 |

Файл `.env` нужен только если запускаешь бота на своём компьютере. На Railway этот файл не используется: все значения задаются в Variables.

Важный момент про сохранность записей: на Railway файлы могут исчезнуть после перезапуска проекта. Если хочешь, чтобы база не пропадала, подключи Volume и попроси помощника (или ChatGPT) сохранять файл базы внутри этой папки. Для короткой проверки это не обязательно.

## Как запустить на компьютере (по желанию)

Это не обязательно. Если хочешь сначала попробовать у себя:

1. Установи Python с сайта [python.org](https://www.python.org/downloads/), если его ещё нет. На Windows поставь галочку «Add Python to PATH».
2. На странице репозитория нажми зелёную кнопку **Code → Download ZIP** и распакуй архив.
3. Открой эту папку в терминале (на Windows это «Командная строка» или PowerShell).
4. Создай окружение и установи зависимости:

```bash
python -m venv venv
```

Потом активируй окружение:

- Windows: `venv\Scripts\activate`
- Mac или Linux: `source venv/bin/activate`

Дальше:

```bash
pip install -r requirements.txt
```

Скопируй файл с настройками:

- Windows: `copy .env.example .env`
- Mac или Linux: `cp .env.example .env`

5. Открой файл `.env` в блокноте и подставь свои значения из таблицы выше. Этот файл нельзя публиковать и нельзя отправлять в чат.
6. Запусти бота командой `python bot.py`.
7. Напиши боту `/start`. Чтобы остановить бота, нажми Ctrl+C в терминале.

Важно: если бот уже запущен на Railway, на время проверки на компьютере останови проект в Railway. Иначе два бота будут мешать друг другу.

## Как пользоваться ботом

- `/start`: краткая памятка.
- `/add`: добавить запись. Бот спросит имя, телефон и заметку.
- `/list`: последние 10 записей.
- `/search` и имя: найти запись.

## Как подстроить под себя

Подумай, что тебе хранить: заявки, идеи, контакты партнёров. Поля в файле `bot.py` сейчас называются «имя», «телефон», «заметка». Их можно переименовать под свою задачу (например, «телефон» в «бюджет»). После правки загрузи файл в свою копию репозитория и проверь, что поиск по-прежнему работает.

## Как понять, что всё получилось

- `/add` сохраняет запись, `/list` её показывает.
- `/search` находит запись по имени.
- Со второго аккаунта бот отвечает «Нет доступа».

## Если не работает

- **Ошибка про `OWNER_ID`.** В переменной должны быть только цифры, без пробелов и без `@`.
- **Записи пропали после перезапуска на Railway.** Файл базы не сохранён на постоянном диске. Подключи Volume, как написано выше.
- **Со второго аккаунта всё открывается.** Скорее всего, `OWNER_ID` не задан или задан не твой. Без него бот для проверки разрешает доступ всем, это небезопасно.
**Бот в Telegram молчит.** Проверь, что в Railway → Variables добавлен верный `BOT_TOKEN`, без пробелов в начале и в конце. Посмотри логи в Railway: там видно ошибку.
- **Railway не видит репозиторий.** При подключении GitHub разреши доступ к нужной копии.
- **Бот отвечает странно или «уже запущен».** Этот же токен, скорее всего, работает ещё где-то (на компьютере или в другом проекте). Оставь только один запуск.

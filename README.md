# Бот-интеграция с внешними данными

Три модуля в одном боте: Google Sheets, почта (IMAP), CRM/API. Подключи нужный — остальные молчат если переменные не заданы. Это готовая основа к Дню 4 курса «ИИ-боты для турагентов».

## Что умеет бот

**Модуль 1 — Google Sheets**
Команды `/sheet` (показать первые 10 строк) и `/search слово` (найти строки по слову). Подходит для любой таблицы: клиенты, заявки, цены, расписание.

**Модуль 2 — Почта (IMAP)**
Проверяет входящие каждые 5 минут и пересылает новые письма в Telegram. Можно фильтровать по отправителю — например, только от туроператоров.

**Модуль 3 — CRM / REST API**
Команда `/crm имя` — ищет клиента или заявку через API внешнего сервиса. Шаблон написан под формат U-ON, но подходит под любую CRM с REST API.

## Что нужно заранее

1. Аккаунт в Telegram.
2. Токен бота: открой @BotFather, команда `/newbot`. Токен нельзя писать в код и в чат.
3. Свой Telegram ID через @userinfobot.
4. Аккаунты GitHub и Railway, как в Дне 0 курса.
5. Дополнительно — зависит от модуля (см. ниже).

## Как запустить на Railway (круглосуточно)

1. Нажми **Fork** на этой странице — получишь свою копию.
2. Войди на [railway.app](https://railway.app) через GitHub.
3. Нажми **New → GitHub Repository**, выбери свою копию.
4. Открой **Variables** и добавь переменные нужного модуля.
5. Напиши боту `/start` — он покажет какие модули активны.

## Переменные (Railway → Variables)

**Обязательные для всех:**

| Переменная | Что это |
|---|---|
| `BOT_TOKEN` | токен из @BotFather |
| `OWNER_ID` | твой Telegram ID |

**Модуль 1 — Google Sheets:**

| Переменная | Что это и где взять |
|---|---|
| `SHEET_ID` | ID таблицы из адресной строки: `docs.google.com/spreadsheets/d/ВОТ_ЭТО/edit` |
| `GOOGLE_CREDENTIALS_JSON` | JSON сервисного аккаунта одной строкой. Инструкция — как в боте calendar-bot из Дня 5 |

Не забудь открыть таблицу на редактирование email сервисного аккаунта (поле `client_email` в JSON).

**Модуль 2 — Почта:**

| Переменная | Что это |
|---|---|
| `EMAIL_HOST` | IMAP-сервер: `imap.yandex.ru`, `imap.gmail.com` и т.д. |
| `EMAIL_USER` | логин почты |
| `EMAIL_PASS` | пароль или app-пароль (в Яндексе и Google нужен отдельный пароль приложения) |
| `EMAIL_FROM_FILTER` | пересылать только письма от (например `@turop.ru`). Оставь пустым — получишь все |

**Модуль 3 — CRM/API:**

| Переменная | Что это |
|---|---|
| `CRM_API_URL` | базовый URL API твоей CRM |
| `CRM_API_KEY` | API-ключ или токен |

Endpoint и поля ответа в `bot.py` помечены TODO — поменяй под свою CRM.

## Как адаптировать

**Sheets — поменять диапазон:** в `bot.py` найди `range="A1:F10"` и замени на свой диапазон.

**Почта — поменять папку:** по умолчанию смотрит INBOX. Найди `imap.select("INBOX")` и замени.

**CRM — поменять endpoint:** найди строку с `/request/search` и замени на нужный путь своей CRM. Поля ответа (`tourist_name`, `status`, `id`) поменяй на поля из документации своей CRM.

**Частота проверки почты:** найди `asyncio.sleep(300)` (это 5 минут) и замени число секунд.

## Как понять, что всё получилось

- `/start` показывает список активных модулей.
- Sheets: `/sheet` возвращает строки таблицы.
- Почта: новое письмо от нужного отправителя приходит в Telegram за 5 минут.
- CRM: `/crm Иванов` возвращает результат из API.

## Если не работает

- **Sheets: «403 Access Not Configured».** Google Sheets API не включён в проекте Google Cloud или таблица не открыта на email сервисного аккаунта.
- **Почта не приходит.** В Яндексе и Gmail нужен отдельный «пароль приложения» — обычный пароль не подходит. Проверь логи Railway.
- **CRM: «422» или пустой ответ.** Неверный endpoint или формат запроса. Сверь с документацией своей CRM.
- **Бот молчит.** Проверь `BOT_TOKEN` в Variables — без пробелов. Посмотри логи в Railway.
